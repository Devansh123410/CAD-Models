# CAD-Models

## 📌 Project Overview
This repository showcases my custom 3D computer-aided design (CAD) models, parametric parts, and engineering drawings. The designs in this repository were built from scratch as part of an independent study program following the open-source engineering lecture series provided by **MIT OpenCourseWare (OCW)**.

* **Academic Curriculum:** MIT OpenCourseWare (Mechanical Engineering / CAD Tracks)
* **Software Environment:** SolidWorks 
* **Focus Areas:** Parametric modeling, assembly constraints, engineering blueprints, and design for manufacturing (DFM).

---

## 🛠️ Skills & Concepts Applied
* **Part Modeling:** Extrusions, revolutions, swept paths, and shell parameters.
* **Assembly Design:** Concentric, coincident, and advanced mechanical mating constraints.
